Présentation

Les TD de JavaScript du semestre 4 constituent une progression structurée autour du langage côté client. Chaque séance introduisait de nouveaux concepts en s'appuyant sur les acquis précédents, aboutissant à des mini-applications interactives fonctionnelles.

Durée : tout le semestre 4  |  Individuel  |  Contrainte : progression notée, approfondissement continu

Contenu des travaux pratiques

  • Manipulation du DOM : sélection, modification et suppression d'éléments HTML dynamiquement.
  • Gestion des événements : écouteurs d'événements, délégation, prévention du comportement par défaut.
  • Formulaires et validation : contrôle côté client des saisies utilisateur avec feedback visuel.
  • Programmation asynchrone : Promises, async/await, gestion des erreurs réseau.
  • Fetch API & API REST : consommation d'APIs externes, affichage de données JSON dynamiquement.
  • Modules ES6 : organisation du code en modules réutilisables, imports/exports.

Ce que j'ai appris

Ces TD m'ont permis de dépasser une vision purement "script" du JavaScript pour adopter une approche plus structurée et professionnelle du langage. L'asynchronisme a été le concept le plus exigeant : comprendre les promesses et l'enchaînement des opérations asynchrones demande un réel effort de modélisation mentale.

La consommation d'APIs REST a ouvert une dimension nouvelle dans ma pratique du développement web : relier une interface à des données réelles, gérer les cas d'erreur et proposer un feedback utilisateur cohérent sont des compétences directement transférables en situation professionnelle.
