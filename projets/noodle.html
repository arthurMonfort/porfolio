Présentation du projet

La SAÉ du semestre 4 nous a placés dans un contexte proche du monde professionnel : reprendre un projet existant, le comprendre, le documenter, puis l'enrichir de nouvelles fonctionnalités. L'application « Noodle » est une plateforme de gestion dont nous devions analyser l'architecture et proposer des évolutions.

Durée : ~8 semaines  |  Équipe  |  Contrainte : reprise de code existant, spécifications à rédiger

Missions réalisées

  • Analyse de l'existant : lecture et documentation du code source de l'application Noodle avant toute modification.
  • Rédaction des spécifications : formalisation des nouvelles fonctionnalités souhaitées dans un cahier des charges structuré.
  • Développement JavaScript : ajout de fonctionnalités interactives côté client, manipulation du DOM, gestion des événements.
  • Amélioration UX : révision de l'interface pour la rendre plus fluide et intuitive pour l'utilisateur final.
  • Gestion de version collaborative : utilisation de Git avec branches et revues de code entre membres de l'équipe.

Humaines

Ce que j'ai appris

Ce projet m'a appris une leçon essentielle : comprendre du code que l'on n'a pas écrit est une compétence à part entière, différente de savoir coder. Avant de pouvoir toucher quoi que ce soit, il fallait lire, cartographier et documenter — une discipline que je sous-estimais jusqu'ici.

La dimension « gestion de projet » a aussi été formatrice : rédiger des spécifications claires, planifier les livraisons et communiquer les avancées en équipe sont des compétences qui se pratiquent, et ce projet m'a donné un cadre concret pour les développer.
